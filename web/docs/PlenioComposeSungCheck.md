# Compose Sung Check (retired)

*Check Sung Words* corrected misheard words in the lyrics **as sung**, after *Export Release* - in 1.2.0's pre-release templates only. It is retired (owner's rule 2026-10-24): the lyrics as sung stay as the lyrics ASR heard them, and misheard words are corrected in one place only, a cover's original lyrics before the render (*Fix Misheard Words*: *Compose Misheard Check*, *Apply Misheard Check*).

This node stays so that a workflow saved with the block still runs: it asks nothing (an empty prompt), so no writer runs. Delete the block from such a workflow.
